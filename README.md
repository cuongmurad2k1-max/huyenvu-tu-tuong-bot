# 🐢 HUYỀN VŨ — TỨ TƯỢNG ULTRA

Một framework RPG Discord lấy cảm hứng từ thế giới Tứ Tượng, có:
- 4 Tứ Tượng + huyết mạch/thức tỉnh
- thần thú/cổ thú
- combat cinematic, combo, crit, dodge, counter
- Boss nhiều phase + World Boss
- bản đồ, bí cảnh, cấm địa
- cốt truyện/chương/nhiệm vụ/NPC
- inventory, equipment, artifact, crafting, shop
- guild/thế lực, PVP, arena
- achievements, leaderboard
- events, rewards, codes
- admin tools
- animation message/GIF/WebP asset support
- JSON database, GitHub/Railway ready

## Chạy
npm install
npm run deploy
npm start

Không commit `.env` hoặc token.
